This screen addresses each requirement:

1. **Items running low with remaining units** — the table lists each low-stock item alongside a "Units Remaining" column.
2. **A way to reorder each item** — the "Reorder" action column provides a per-row reorder control.
3. **The threshold that triggers the warning** — shown prominently in the top alert banner (20 units) and repeated in a per-row "Threshold" column for clarity.
4. **A way to search items** — the search input at the top filters by product name or SKU.
