This screen covers every numbered requirement:

1. **Items running low with remaining units** — the table lists each low-stock item (with name and SKU) alongside its **Remaining Units** column.
2. **A way to reorder each item** — each row has a **Reorder** action in the Action column, plus batch **Reorder Selected** and **Reorder All Low Items** buttons below the table.
3. **The threshold that triggers the warning** — surfaced both in the top **Alert** ("Threshold: 20 units") and as a per-row **Threshold** column for clarity.
4. **A way to search items** — the search input at the top filters by product name or SKU.
