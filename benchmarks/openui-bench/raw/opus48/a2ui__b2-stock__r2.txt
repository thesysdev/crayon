This screen covers every requirement:

1. **Items running low with remaining units** — Each item card shows the product name/SKU with a colored `Tag` displaying units left (red for critical, amber for approaching threshold).
2. **A way to reorder each item** — Every item has its own **Reorder** button wired to a per-SKU action.
3. **The threshold that triggers the warning** — The amber `Callout` at the top states the **10-unit** threshold, echoed in the footer.
4. **A way to search items** — A search `Form` with an input (name/SKU) and a Search button sits above the list.
