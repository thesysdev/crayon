1. **Uptime this quarter** (KPI Card / Metric block)
2. **CPU and memory usage over the past 24h** (Line Chart with multiple series)
3. **Current Error Rate** (Callout / Metric indicator)
4. **Open Incidents with Severity** (Interactive Table)
5. **Region Selector** (Form dropdown filter)
6. **Top 5 Slowest Endpoints with Latency** (Horizontal Bar Chart & Table view)
7. **Alert Threshold Setting** (Form control with slider and input)
8. **Acknowledge Incident Action** (Actionable dialog / trigger button)
