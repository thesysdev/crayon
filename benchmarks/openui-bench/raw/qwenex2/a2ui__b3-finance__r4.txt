This covers all seven requirements:

| # | Requirement | Component |
|---|---|---|
| 1 | Cash on hand | KPI table row → **$842,000** |
| 2 | Monthly burn | KPI table row → **$127,500** |
| 3 | Months of runway | KPI table row → **6.6 months** |
| 4 | Expenses by category | Donut chart with 5 categories |
| 5 | Transactions > $10k | Detail table with 5 line items |
| 6 | Switch month | Select dropdown (Jan–Jul 2025) |
| 7 | Download statement | "Download Statement (PDF)" button |
