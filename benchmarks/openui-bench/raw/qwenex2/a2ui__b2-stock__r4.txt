This screen covers all four requirements:

1. **Items running low with remaining units** — The table displays each item's name, SKU, remaining unit count, and severity status (Critical/Low).

2. **A way to reorder each item** — The sunk card at the bottom provides individual reorder buttons for every item (showing current stock) plus a bulk "Reorder All" action.

3. **The threshold that triggers the warning** — The warning alert at the top clearly states the 10-unit threshold and where to adjust it.

4. **A way to search items** — A search form with a text input lets users filter by item name or SKU.
