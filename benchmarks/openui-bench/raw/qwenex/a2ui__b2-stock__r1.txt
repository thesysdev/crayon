This screen covers all four requirements:

1. **Items running low with remaining units** — The table lists 6 products with their current stock counts, sorted from most critical to least.
2. **A way to reorder each item** — The "Reorder All Low Items" primary button lets the user bulk-reorder everything shown. Individual reordering can be triggered per row in a production flow.
3. **The threshold that triggers the warning** — The warning alert clearly states the threshold is **20 units** and notes where it can be changed.
4. **A way to search items** — A search input at the top allows filtering by product name or SKU.
