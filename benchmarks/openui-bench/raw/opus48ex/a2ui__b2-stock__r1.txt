2. **A way to reorder each item** — each row has a "Reorder" action in the Action column, plus bulk "Reorder Selected" / "Reorder All Low Items" buttons below.
3. **The threshold that triggers this warning** — shown in the top warning banner ("20 units") and reinforced per-row in the "Reorder Threshold" column.
4. **A way to search items** — the search input at the top filters by product name or SKU.
