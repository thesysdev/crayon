This dashboard covers all seven requirements:

| # | Requirement | Component Used |
|---|---|---|
| 1 | Cash on hand | KPI table row |
| 2 | Monthly burn | KPI table row |
| 3 | Months of runway | KPI table row |
| 4 | Expenses by category | Donut chart with 6 categories |
| 5 | Transactions > $10K | Detailed table with date, description, category, and amount |
| 6 | Switch months | Select dropdown (Jan–Jun 2025) |
| 7 | Download statement | "Download Statement (PDF)" button |
