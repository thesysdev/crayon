This view covers all four requirements:

1. **Items running low** — The table lists each product with its remaining unit count and a color-coded status indicator.
2. **Reorder each item** — Each row has a "Reorder" action, plus a bulk "Reorder All Items" button at the bottom.
3. **Threshold display** — The warning alert at the top clearly states the 10-unit threshold that triggers the alert.
4. **Search** — A search input field lets users filter items by name or SKU.
