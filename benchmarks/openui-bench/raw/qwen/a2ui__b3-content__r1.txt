| # | Requirement | Where |
|---|---|---|
| 1 | Drafts with status | **Content** tab → Drafts table (title, status, last updated) |
| 2 | Published this week | **Content** tab → Published table with dates & views |
| 3 | Most-read article | **Content** tab → Green callout highlighting the top piece |
| 4 | 30-day readership | **Analytics** tab → Area chart with daily reader counts |
| 5 | Narrow by category | **Analytics** tab → Category select filter above the chart |
| 6 | Schedule a piece | **Actions** tab → Form with title input + date picker |
| 7 | Comments awaiting reply | **Comments** tab → Alert banner + full comment table |
| 8 | Start a new draft | **Actions** tab → Prominent "+ New Draft" button |
