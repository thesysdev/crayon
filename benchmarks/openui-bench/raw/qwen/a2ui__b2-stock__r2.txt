This screen covers all four requirements:

| # | Requirement | Implementation |
|---|---|---|
| 1 | **Items running low + remaining units** | Table with Item Name, SKU, and Remaining columns showing 8 low-stock products |
| 2 | **Way to reorder each item** | "Reorder" action column per row + a "Reorder All" bulk button at the bottom |
| 3 | **Threshold that triggers the warning** | Warning callout at the top stating the 10-unit threshold, plus a Threshold column in the table for per-item reference |
| 4 | **Way to search items** | Search input field (by name or SKU) placed above the table |

Additional UX details included:
- **Status indicators** (🔴 Critical / 🟡 Low) for quick visual triage
- **Summary footer** with counts of affected and critical items
- **Accessible labels** on the search field
