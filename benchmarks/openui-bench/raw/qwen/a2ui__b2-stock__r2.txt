This view covers all four requirements:

1. **Items running low with remaining units** — The table lists each flagged item with its current stock count and a color-coded status indicator (Critical ≤ 3, Low ≤ 7).

2. **A way to reorder each item** — Each row has a "Reorder" action column, plus a bulk "Reorder All Flagged Items" button at the bottom.

3. **The threshold that triggers the warning** — A prominent warning alert at the top states the threshold is **10 units** and hints where to change it.

4. **A way to search items** — A search input field lets users filter by item name or SKU.
