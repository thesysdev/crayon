

Here's the store manager's daily console — one screen covering all 12 items:

1. **Sales vs target** → progress card
2. **Foot traffic** → hourly area chart
3. **Best sellers** → ranked unit bars
4. **Out of stock** → alert + SKU table
5. **On shift** → roster table
6. **Avg basket** → KPI tile
7. **Returns** → KPI tile
8. **Promotions** → performance table
9. **Registers** → status table
10. **Reorder** → reorder form (OOS items preloaded)
11. **Switch store** → picker in the header
12. **Week vs last week** → grouped bar chart
