This dashboard covers all seven requirements:

| # | Requirement | Implementation |
|---|---|---|
| 1 | Cash on hand | KPI table row → **$842,500** |
| 2 | Monthly burn | KPI table row → **$127,300** |
| 3 | Months of runway | KPI table row → **6.6 months** |
| 4 | Expenses by category | Donut chart with 5 categories |
| 5 | Transactions > $10k | Detailed table with date, description, category, and amount |
| 6 | Switch months | Select dropdown (Jun–Mar 2025) |
| 7 | Download statement | "Download Statement" button + "Export as CSV" action |
