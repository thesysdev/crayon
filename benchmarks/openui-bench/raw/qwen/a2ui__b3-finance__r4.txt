This covers all seven requirements:

| # | Requirement | Component Used |
|---|---|---|
| 1 | Cash on hand | KPI table row → **$847,200** |
| 2 | Monthly burn | KPI table row → **$142,500** |
| 3 | Months of runway | KPI table row → **5.9 months** (with warning note) |
| 4 | Expenses by category | Donut **PieChart** with 4 categories |
| 5 | Transactions > $10K | **Table** with date, description, category, amount |
| 6 | Switch month | **Select** dropdown (Jan–Jun 2025) with Apply button |
| 7 | Download statement | Primary **Button** → "Download Statement (PDF)" |
