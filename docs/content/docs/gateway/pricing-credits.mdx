---
title: Pricing & Credits
description: Understand how managed model usage, Gateway credits, and BYOK interact.
---

Gateway usage can be funded with managed credits or routed through a provider key configured with [BYOK](/docs/gateway/byok).

- Requests to a provider with a configured organization key use that provider key.
- Requests without a matching provider key use available Gateway credits.
- If a request requires credits and the organization has none available, the request fails with an out-of-credits error.

<Callout type="info">
  Detailed rates and credit policies are still being finalized. The billing view in the Thesys
  Console is the current source of truth for your organization.
</Callout>

The API surfaces and OpenUI Lang correction behavior are the same whether a request uses managed credits or BYOK.
