---
title: Limits
description: Understand the account and request limits applied by the Gateway.
---

Gateway limits protect provider capacity and keep streaming requests predictable. Limits can vary by account, model, provider, and API surface.

When a request exceeds an active limit, the Gateway returns an API error rather than silently truncating application behavior. Handle these failures using the status and error information described in [Errors](/docs/gateway/api/errors).

<Callout type="info">
  The public limits table is being finalized. Check the Thesys Console for the limits currently
  applied to your organization.
</Callout>

For production traffic, treat limit errors as explicit operational signals and monitor them through your normal application telemetry.
