title: Quick Start
description: Define an OpenUI component library, generate through the Gateway, and render the response in React.
---

This guide builds the smallest complete OpenUI path: application-owned components, a serialized library contract, Gateway generation, and a React renderer.

## 1. Install OpenUI

```bash tab="pnpm" tab-group="pkg"
pnpm add @openuidev/react-lang @openuidev/thesys-server openai zod
pnpm add -D @openuidev/cli
```

```bash tab="npm" tab-group="pkg"
npm install @openuidev/react-lang @openuidev/thesys-server openai zod
npm install -D @openuidev/cli
```

## 2. Define the components

Create `src/lib/openui.tsx`:

```tsx
import { createLibrary, defineComponent } from "@openuidev/react-lang";
import { z } from "zod/v4";

const Metric = defineComponent({
  name: "Metric",
  description: "Displays one labeled business metric.",
  props: z.object({
    label: z.string(),
    value: z.string(),
    change: z.string().optional(),
  }),
  component: ({ props }) => (
    <article className="rounded-lg border p-4">
      <p>{props.label}</p>
      <strong>{props.value}</strong>
      {props.change ? <small>{props.change}</small> : null}
    </article>
  ),
});

const Dashboard = defineComponent({
  name: "Dashboard",
  description: "A titled collection of metrics.",
  props: z.object({
    title: z.string(),
    metrics: z.array(Metric.ref),
  }),
  component: ({ props, renderNode }) => (
    <section>
      <h2>{props.title}</h2>
      <div className="grid gap-3 sm:grid-cols-3">{renderNode(props.metrics)}</div>
    </section>
  ),
});

export const library = createLibrary({
  root: "Dashboard",
  components: [Dashboard, Metric],
});
```

The Zod schemas are the contract shared by the model, Gateway correction layer, parser, and renderer.

## 3. Generate the server contract

Serialize the component library so the server can send it with generation instructions:

```bash
npx openui generate src/lib/openui.tsx --spec --out src/lib/openui.spec.json
```

Regenerate this file whenever component names or schemas change.

## 4. Generate through the Gateway

Create a Gateway API key in the [Thesys Console](https://console.thesys.dev/keys) and store it as `THESYS_API_KEY` on the server.

```ts title="src/lib/generate.ts"
import library from "./openui.spec.json";
import { generateSystemPrompt } from "@openuidev/thesys-server";
import OpenAI from "openai";

const gateway = new OpenAI({
  apiKey: process.env.THESYS_API_KEY,
  baseURL: "https://api.thesys.dev/v1/embed",
});

export function generateInterface(input: string) {
  return gateway.responses.create({
    model: "openai/gpt-5",
    input,
    instructions: generateSystemPrompt({ library }),
    stream: true,
  });
}
```

Call `generateInterface()` from a server route and relay its Responses API stream to the browser. The Gateway validates the OpenUI Lang against the supplied library and corrects invalid output while it streams.

## 5. Render the stream

Pass the accumulated OpenUI Lang text to `<Renderer />`. Set `isStreaming` until the server stream closes.

```tsx
"use client";

import { Renderer } from "@openuidev/react-lang";
import { library } from "@/lib/openui";

export function GeneratedInterface({ response, isStreaming }) {
  return (
    <Renderer
      response={response}
      library={library}
      isStreaming={isStreaming}
      onAction={(action) => console.log(action)}
    />
  );
}
```

As soon as the model defines `root`, the renderer can display the dashboard shell. Referenced metrics fill in as later statements arrive.

## Add a conversation UI

The renderer does not require a particular message or agent framework. Connect this same library through [assistant-ui](/docs/integrations/assistant-ui), [Agent Interface](/docs/agent/agent-interface/getting-started/introduction), [Vercel AI SDK](/docs/integrations/vercel-ai-sdk), [LangChain](/docs/integrations/langchain), or [your own UI](/docs/integrations/build-your-own-ui).
