---
title: Charts
description: Visualization blocks for comparison, trends, proportions, relationships, and progress.
---

Charts turn structured values into visual comparisons. Select a chart based on the analytical question, keep labels clear, and use tables when exact values matter more than patterns.

Configurations describe generation choices you can request through prompting.

## Bar

Compares values across discrete categories using vertical bars. Bar charts work well when category labels are short and the baseline comparison is important.

![Bar chart](/design-system/bar-chart.png)

### Configurations

#### Variant

| Option  | Description                       |
| ------- | --------------------------------- |
| Grouped | Shows series side by side.        |
| Stacked | Shows series as parts of a total. |

#### Mode

| Configuration | Description                                      |
| ------------- | ------------------------------------------------ |
| Scrollable    | Allows horizontal scrolling for larger datasets. |

## Horizontal Bar

Compares values across categories using horizontal bars. Horizontal bar charts work well with long labels or ranked data.

![Horizontal bar chart](/design-system/horizontal-bar-chart.png)

## Line

Shows change across time or another ordered sequence. Line charts are best for trends, rate of change, and relationships between continuous series.

![Line chart](/design-system/line-chart.png)

### Configurations

#### Mode

| Configuration | Description                                    |
| ------------- | ---------------------------------------------- |
| Scrollable    | Allows horizontal scrolling for longer series. |

## Area

Shows trends with the space below each line filled. Area charts emphasize magnitude, cumulative totals, or volume over an ordered sequence.

![Area chart](/design-system/area-chart.png)

### Configurations

#### Mode

| Configuration | Description                                    |
| ------------- | ---------------------------------------------- |
| Scrollable    | Allows horizontal scrolling for longer series. |

## Pie

Shows a part-to-whole breakdown as circular slices. Pie charts are most effective with a small number of clearly different values.

![Pie chart](/design-system/pie-chart.png)

## Donut

Shows a part-to-whole breakdown with a central area available for a total or primary metric.

![Donut chart](/design-system/donut-chart.png)

## Scatter

Plots points across two numeric axes to reveal correlation, distribution, clusters, and outliers.

![Scatter chart](/design-system/scatter-chart.png)

## Radar

Plots values across radial axes to compare profiles, strengths, and trade-offs.

![Radar chart](/design-system/radar-chart.png)

## Radial

Displays values as radial bars around a shared center. Radial charts work best for a small set of progress-style or comparative metrics.

![Radial chart](/design-system/radial-chart.png)
