OpenUI uses design tokens to keep every generated interface visually consistent. Each token is available as a CSS custom property with the `--openui-` prefix and can be overridden globally or within a specific scope.

## Typography foundations

Foundation typography tokens define the reusable families, sizes, weights, line heights, and tracking values used to build OpenUI text styles.

| Name                                 | Description                        |
| ------------------------------------ | ---------------------------------- |
| `--openui-font-body`                 | Font family for body text.         |
| `--openui-font-code`                 | Font family for code.              |
| `--openui-font-heading`              | Font family for headings.          |
| `--openui-font-label`                | Font family for labels.            |
| `--openui-font-numbers`              | Font family for numerical content. |
| `--openui-font-size-2xs`             | 10px font size.                    |
| `--openui-font-size-xs`              | 12px font size.                    |
| `--openui-font-size-sm`              | 14px font size.                    |
| `--openui-font-size-md`              | 16px font size.                    |
| `--openui-font-size-lg`              | 18px font size.                    |
| `--openui-font-size-xl`              | 20px font size.                    |
| `--openui-font-size-2xl`             | 24px font size.                    |
| `--openui-font-size-3xl`             | 28px font size.                    |
| `--openui-font-size-4xl`             | 32px font size.                    |
| `--openui-font-size-5xl`             | 36px font size.                    |
| `--openui-font-weight-regular`       | Regular font weight.               |
| `--openui-font-weight-medium`        | Medium font weight.                |
| `--openui-font-weight-bold`          | Bold font weight.                  |
| `--openui-font-weight-heavy`         | Heavy font weight.                 |
| `--openui-line-height-body`          | Line height for body text.         |
| `--openui-line-height-heading`       | Line height for compact headings.  |
| `--openui-line-height-heading-large` | Line height for large headings.    |
| `--openui-line-height-label`         | Line height for labels.            |
| `--openui-line-height-code`          | Line height for code.              |
| `--openui-letter-spacing-normal`     | Default letter spacing.            |
| `--openui-letter-spacing-tight`      | Tight letter spacing.              |
| `--openui-letter-spacing-tighter`    | Tightest letter spacing.           |

  --openui-font-code: "SFMono-Regular", Menlo, monospace;

  --openui-font-size-xl: 20px;
  --openui-font-size-2xl: 24px;
  --openui-font-size-3xl: 28px;
  --openui-font-size-4xl: 32px;
  --openui-font-size-5xl: 36px;
  --openui-font-weight-regular: 375;
  --openui-font-weight-medium: 475;
  --openui-font-weight-bold: 600;

  --openui-line-height-body: 1.5;
  --openui-line-height-heading: 1.25;
  --openui-line-height-heading-large: 1.1;
