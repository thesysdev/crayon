---
title: Forms
description: Input and selection blocks for collecting structured information.
---

Form blocks collect choices, dates, and short text from people. Select the most direct control for the task, provide clear labels, and keep generated forms focused on the minimum information required.

Configurations describe generation choices you can request through prompting.

## Checkbox

Presents multiple options that can be turned on or off independently. Checkboxes are appropriate when any number of choices may apply.

![Checkbox](/design-system/checkbox.png)

| Configuration | Description                           |
| ------------- | ------------------------------------- |
| Description   | Adds optional text below each choice. |

## Chips

Presents compact, pill-shaped controls for filters, tags, and lightweight selections.

![Chips](/design-system/chips.png)

| Configuration            | Description                        |
| ------------------------ | ---------------------------------- |
| Selection                | Allows one or multiple selections. |
| Content                  | Uses text or an icon.              |
| Disabled item (optional) | Makes a chip unavailable.          |

## Option Cards

Presents selectable cards with a title, subtitle, and optional icon or image. Card choices are useful when options need more explanation or visual identity than a standard control can provide.

![Option cards](/design-system/option-cards.png)

| Configuration            | Description                        |
| ------------------------ | ---------------------------------- |
| Selection                | Allows one or multiple selections. |
| Top content              | Uses text, an icon, or an image.   |
| Disabled item (optional) | Makes a card unavailable.          |

## Date Picker

Presents a calendar control for choosing a date. Date pickers help prevent formatting errors and make calendar context visible.

![Date picker](/design-system/date-picker.png)

## Input Field

Collects short, single-line text such as a name, search query, or quick answer.

![Input field](/design-system/input-field.png)
