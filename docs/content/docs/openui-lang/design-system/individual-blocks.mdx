---
title: Individual Blocks
description: Focused blocks for actions, statuses, media, lists, and structured content.
---

Individual blocks represent focused content and interaction patterns. They can stand alone or be composed inside navigation and card structures.

Configurations describe generation choices you can request through prompting.

## Accordion

Organizes content into vertically stacked, collapsible sections. Accordions are useful for optional detail, FAQs, and progressive disclosure.

![Accordion block](/design-system/accoridan.png)

## Buttons

Presents a single action or a related group of actions.

![Buttons](/design-system/buttons.png)

| Configuration | Description                                    |
| ------------- | ---------------------------------------------- |
| Type          | Uses normal or destructive styling.            |
| Variant       | Uses primary, secondary, or tertiary emphasis. |
| Content       | Uses text, an icon, or both.                   |

## Callout

Highlights important information, warnings, success states, or guidance without breaking the surrounding content flow.

![Callout](/design-system/callout.png)

| Option  | Description                   |
| ------- | ----------------------------- |
| Neutral | Shows general information.    |
| Info    | Shows informational guidance. |
| Success | Shows a successful outcome.   |
| Warning | Shows a warning.              |
| Danger  | Shows an error or risk.       |

## Image Items

Displays a single image as part of generated content. Images can provide evidence, context, comparison, or visual orientation.

![Image gallery](/design-system/image-gallery.png)

## Lists

Presents vertical collections of items or ordered steps.

![List block](/design-system/list.png)

| Configuration              | Description                          |
| -------------------------- | ------------------------------------ |
| Marker                     | Uses a number, icon, or image.       |
| Supporting text (optional) | Adds text below each title.          |
| Interactivity              | Makes each item static or clickable. |

## Entity List

Presents key-value rows in a scannable two-column layout.

![Entity list](/design-system/entity-list.png)

| Configuration     | Description                                     |
| ----------------- | ----------------------------------------------- |
| Header (optional) | Adds a header row.                              |
| Values            | Uses text or number values in the right column. |
| Footer (optional) | Adds a footer row.                              |

## Tables

Presents structured data in rows and columns.

![Table block](/design-system/table.png)

### Configurations

#### Cell content

| Option | Description               |
| ------ | ------------------------- |
| Text   | Shows text in a cell.     |
| Number | Shows a number in a cell. |
| Tag    | Shows status or metadata. |
| Button | Adds a row-level action.  |

## Tags

Displays a compact status, category label, or key attribute.

![Tags](/design-system/tags.png)

| Configuration | Description                                              |
| ------------- | -------------------------------------------------------- |
| Variant       | Uses neutral, info, success, warning, or danger styling. |
| Content       | Uses text, an icon, or both.                             |
