Cards group related information into distinct containers, making content easier to scan and compare.

## Composite

A general-purpose card that can contain almost any combination of content.

![Composite cards](/design-system/Composite-cards.png)

| Configuration     | Description                                  |
| ----------------- | -------------------------------------------- |
| Header            | Identifies the card with text and/or media.  |
| Body              | Adds one or more ordered content blocks.     |
| Footer (optional) | Adds a price metric, action button, or both. |
| Interactivity     | Makes the card static or clickable.          |
| Arrangement       | Shows cards in a grid or carousel.           |

#### Header options

| Option       | Description                     |
| ------------ | ------------------------------- |
| Text         | Uses text only.                 |
| Icon + text  | Uses an icon with text.         |
| Image + text | Uses an image with text.        |
| Image        | Uses a large, full-width image. |

#### Body block options

| Option         | Description                                               |
| -------------- | --------------------------------------------------------- |
| Text           | Adds standard text.                                       |
| Highlight text | Adds emphasized text.                                     |
| Entity list    | Presents key-value rows in a scannable two-column layout. |
| Metric         | Adds a key number.                                        |
| Charts         | Adds any supported chart.                                 |
| Image          | Adds supporting imagery.                                  |

#### Footer options

| Option       | Description                 |
| ------------ | --------------------------- |
| Price metric | Adds a price or key metric. |
| Button       | Adds an action button.      |

## Visual Cards

An image-led card that layers text over a full-bleed image.

![Visual cards](/design-system/visual-cards.png)

| Configuration              | Description                          |
| -------------------------- | ------------------------------------ |
| Header (optional)          | Adds an identifying or category tag. |
| Supporting text (optional) | Adds subtext.                        |
| Interactivity              | Makes the card static or clickable.  |
| Arrangement                | Shows cards in a grid or carousel.   |

## Snippet

A compact card for repeated key-value information or quick-scan metrics.

![Snippet cards](/design-system/snippet-cards.png)

| Configuration              | Description                                                  |
| -------------------------- | ------------------------------------------------------------ |
| Left media                 | Uses an icon or image.                                       |
| Supporting text (optional) | Adds subtext.                                                |
| Right content (optional)   | Adds text, a number, or a pair of text and/or number values. |
| Interactivity              | Makes the card static or clickable.                          |

## Context

A grid of cards that presents each subject with a short title and contextual details.

![Context cards](/design-system/context-card.png)

| Configuration           | Description                         |
| ----------------------- | ----------------------------------- |
| Title style             | Uses a tag or text title.           |
| Body content (optional) | Adds text or a number.              |
| Background (optional)   | Adds a background image.            |
| Interactivity           | Makes the card static or clickable. |

## Overview

A summary card for an entity with identifying content and a supporting value.

![Overview cards](/design-system/overview-cards.png)

| Configuration                           | Description                                                        |
| --------------------------------------- | ------------------------------------------------------------------ |
| Top media (optional)                    | Adds an icon or image.                                             |
| Supporting text (optional)              | Adds subtext.                                                      |
| Icon tone (with icon)                   | Uses neutral, info, success, warning, danger, or inverted styling. |
| Bottom content                          | Uses a number or text.                                             |
| Trend indicator (optional, with number) | Adds a trend to numerical content.                                 |
| Interactivity                           | Makes the card static or clickable.                                |
| Arrangement                             | Shows cards in a grid or carousel.                                 |
