---
title: Navigation
description: Blocks for organizing related content and moving between views.
---

Navigation blocks give generated interfaces a clear information hierarchy. Use them to group related content, reduce visual density, and help people move between connected views.

Configurations describe generation choices you can request through prompting.

## Section

Groups related content under a clear heading. Sections work well for long responses that need visible hierarchy without separating the content into entirely different views.

![Section block](/design-system/Section.png)

### Configurations

| Variant            | Description                                     |
| ------------------ | ----------------------------------------------- |
| Default / Foldable | Keeps content visible or allows it to collapse. |

## Tabs

Presents related views in a compact tabbed interface. Tabs are useful when each view is equally important but showing every view at once would make the response difficult to scan.

![Tabs block](/design-system/Tabs.png)

### Configurations

| Configuration | Description                                |
| ------------- | ------------------------------------------ |
| Image / Icon  | Adds optional media before each tab label. |
| Subtitle      | Adds optional text below each tab label.   |
