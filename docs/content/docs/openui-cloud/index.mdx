OpenUI Cloud is the managed layer that runs OpenUI applications in production. It provides everything a generative UI application needs: the LLM APIs of leading providers with automatic fallbacks, conversation and artifact storage, validation that catches broken model output before it renders, and complete artifacts beyond chat — slides and reports. Open-source OpenUI covers the rendering itself; the layers around it are what Cloud runs, so teams ship the product rather than operating the infrastructure.

## Why OpenUI Cloud

Open-source OpenUI and OpenUI Cloud share the same foundation: OpenUI Lang and the rendering model are identical in both. The difference is operational — with open source, the production layers are built and run by the application team; with Cloud, they are managed. What follows is what that management covers.

### Reliable model access

The LLM APIs of leading providers are available through OpenUI Cloud's APIs, billed at cost. Provider accounts, credentials, and integrations are handled by Cloud, and when a model or LLM provider becomes unavailable, requests reroute to a fallback automatically — the application stays up. For details, see [Reliable model access](/docs/openui-cloud/production/model-access).

### Output validation & correction

Models produce malformed responses. Cloud detects invalid output and corrects it in real time, in the stream, so broken model output never reaches the interface. For details, see [Output validation & correction](/docs/openui-cloud/production/output-validation).

### Conversation & artifact storage

Cloud persists conversations, actions, and generated artifacts automatically — no database or storage layer on the application side. Returning users find their threads and artifacts intact.

### Slides, reports and dashboards

Cloud generates complete presentations, reports, and interactive dashboards out of the box — designed templates, interactive viewers, and print-ready layouts for export. Building artifact types from scratch, with their templates, renderers, and storage, is not required. For details, see [Slides](/docs/openui-cloud/build/slides) and [Reports](/docs/openui-cloud/build/reports).

### Production-grade UI components

Generated interfaces render with production-tested, responsive components built for generative UI, consistent across browsers, devices, and screen sizes — beyond the basic components included with open source. For details, see [Generative UI for agents](/docs/openui-cloud/build/chat).

### Observability

Cloud will provide built-in visibility into how models and rendered interfaces behave in production — *coming soon*.
