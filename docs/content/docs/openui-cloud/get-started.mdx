The OpenUI CLI scaffolds a complete Next.js application connected to OpenUI Cloud: streaming chat with generative UI, slides and reports, and conversation history, with no boilerplate to write. The CLI walks through setup, including the API key.

<FakeVisual label="30-second GIF: scaffolded app answering with a chart, then generating a presentation" height={300} />

## Create

Run the create command and answer the prompts. When asked to choose an AI setup, select **OpenUI Cloud**.

```bash tab="pnpm" tab-group="pkg"
pnpx @openuidev/cli@latest create
```

```bash tab="bun" tab-group="pkg"
bunx @openuidev/cli@latest create
```

```bash tab="yarn" tab-group="pkg"
yarn dlx @openuidev/cli@latest create
```

```bash tab="npm" tab-group="pkg"
npx @openuidev/cli@latest create
```

## Run

Start the dev server:

```bash tab="pnpm" tab-group="pkg"
pnpm dev
```

```bash tab="bun" tab-group="pkg"
bun dev
```

```bash tab="yarn" tab-group="pkg"
yarn dev
```

```bash tab="npm" tab-group="pkg"
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and send a message. Ask for a chart, then a slide deck on the same topic. Close the tab and return — the conversation is still there.

## What the scaffold includes

- A working chat interface with generative UI — responses render as interactive components.
- Slides and reports enabled out of the box.
- Conversation history and artifact storage, with no database to set up.
- A codebase ready to be shaped into a product.

For the capabilities in detail, see [Introduction](/docs/openui-cloud). For a technical overview of the architecture, see [How it works](/docs/openui-cloud/how-it-works).
