---
title: Reliable model access
description: "Access to models from multiple providers through OpenUI Cloud's APIs, with automatic fallback when a model or provider is unavailable."
---

OpenUI Cloud provides access to models from multiple providers through its APIs, and keeps requests succeeding when a model or provider is unavailable.

<FakeVisual label="OpenUI Cloud in front of multiple model providers, with one path unavailable and traffic routed through another" height={280} />

- **Model access across providers** — applications reach models from supported providers through OpenUI Cloud's APIs. Provider accounts, credentials, and connections are managed by Cloud, and model usage is billed at cost. The application names a model per request, so switching models requires no application change.
- **Automatic fallback** — when a selected model or its provider is unavailable, Cloud reroutes the request to a fallback without application involvement. Requests continue to succeed during a provider outage or slowdown.
- **Output normalization** — generated output is normalized across providers and model versions, so an interface behaves consistently when the underlying model changes. Switching models requires no re-testing of the interface and no change to the component library.
