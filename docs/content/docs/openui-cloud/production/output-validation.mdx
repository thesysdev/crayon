---
title: Output validation & correction
description: "Every response validated against its component library, with invalid output detected and corrected in the streaming path before it reaches the interface."
---

OpenUI Cloud validates every model response before it renders, and corrects invalid output in real time.

<FakeVisual label="Before/after: malformed model output on the left, the corrected rendered interface on the right" height={300} />

- **Validation against the component library** — each response is checked against the component library it was generated for, the built-in library or one the application registered. Validation detects malformed structures, nonexistent components, and unrenderable content.
- **Real-time correction** — correction happens in the streaming path, not as a retry the user waits through. Invalid output is corrected before it leaves Cloud, so it does not reach the interface.
- **Consistency across models** — validation and correction run server-side, so behavior stays consistent as model providers and versions change underneath the application. Provider-specific quirks are normalized before rendering.
