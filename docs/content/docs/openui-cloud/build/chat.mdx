title: Generative UI for agents
description: "Agent responses as interfaces adapted to the conversation — forms when the agent needs input, the right chart for the data, components that fit the context."
---

With generative UI, the agent composes the interface for each response, so what renders fits the moment it was made for. OpenUI Cloud provides LLM APIs that return agent responses as generative UI — validated, streamed, and rendered live in the application. Applications can render with the built-in component library or bring their own.

## Built-in component library

Cloud's built-in library provides production-grade components tested for responsive, consistent behavior across browsers, devices, and screen sizes.

### Forms and inputs

Form components — text fields, selects, options, and defaults — that compose into complete forms, collecting structured input in one step rather than over several text messages.

## Bring your own component library

Applications can bring their own component library — their design system and custom components — and Cloud's production features apply to it: output validation, model reliability, and consistent behavior across models and providers.
