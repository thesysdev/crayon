Reports are complete structured documents generated from a prompt or an ongoing conversation. Each report is composed from designed page and content-block components, so the output reads as a laid-out document rather than a block of text. Reports stay connected to the conversation that produced them — refinements are requested in conversation, and every version is kept — and each renders in an in-product reading view with a print-ready layout for export.

Reports are built with the following components.

### Pages

Page components — standard, minimal, and dramatic front pages, content pages, and a generated table of contents — that give a report its overall structure.

<FakeVisual label="Report pages: a dramatic front page, a content page, and a table of contents" height={240} />

### Text

Text components — prose, inline headers, headlines, and statements — that carry the narrative sections of a document.

<FakeVisual label="A report section combining a headline, prose, and a statement" height={240} />

### Metrics

Metric components — key metrics, key statements, spotlight metrics, and numbered key points — that present the figures a report is built around.

<FakeVisual label="A key-metrics row and a spotlight metric inside a report section" height={240} />

### Tables and collections

Collection components — lists, tables, summary grids, mini cards, feature highlights, tags, and visual cards — that organize comparisons and groupings.

<FakeVisual label="A summary grid and a comparison table inside a report" height={240} />

### Charts and media

Chart and image components — interactive bar, line, area, and pie charts, plus image blocks — that visualize data and illustrate the content.
