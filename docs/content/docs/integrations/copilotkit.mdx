---
title: CopilotKit
description: Connect a CopilotKit agent experience to Gateway-backed OpenUI generation and rendering.
---

CopilotKit can continue to own the agent runtime, conversation surface, and application context while OpenUI handles generated interface output.

The integration boundary is the same as other agent stacks:

1. Configure the runtime's model client to send generation through the [Gateway](/docs/gateway).
2. Include the system prompt generated from your OpenUI component library.
3. Preserve the streamed OpenUI Lang response in the assistant message or tool result.
4. Render that value with the OpenUI `<Renderer />` and your component library.
5. Forward generated component actions through the CopilotKit application action flow.

<Callout type="info">
  A dedicated CopilotKit adapter is not currently part of the OpenUI package set. Keep the
  integration at the streamed text and renderer boundary so it does not depend on private runtime
  APIs.
</Callout>

Use [Build Your Own UI](/docs/integrations/build-your-own-ui) for the renderer contract and [Generative UI Quickstart](/docs/gateway/generate-openui-lang) for the recommended generation path.
