title: assistant-ui
description: Let assistant-ui own the conversation and tool lifecycle while OpenUI renders generated interfaces.
---

Use `@openuidev/assistant-ui` when an application already uses assistant-ui for threads, messages, and tools. The integration registers OpenUI as Tool UI, adds the model instructions, and returns user interactions through assistant-ui's tool-result flow.

The recommended production path sends the assistant-ui runtime's model requests through the [Gateway](/docs/gateway). The UI integration remains the same regardless of which supported model is selected behind the Gateway.

## Install

```bash tab="pnpm" tab-group="pkg"
pnpm add @openuidev/assistant-ui @assistant-ui/react @openuidev/react-ui @openuidev/react-lang
```

```bash tab="npm" tab-group="pkg"
npm install @openuidev/assistant-ui @assistant-ui/react @openuidev/react-ui @openuidev/react-lang
```

## Register OpenUI

```tsx
"use client";

import {
  AssistantRuntimeProvider,
  AuiConfig,
  AuiProvider,
  Tools,
  useAui,
  useAssistantInstructions,
} from "@assistant-ui/react";
import { openuiIntegration } from "@openuidev/assistant-ui";

function OpenUIInstructions() {
  useAssistantInstructions(openuiIntegration.instructions);
  return null;
}

function OpenUIConfig({ children }) {
  const aui = useAui();
  const config = AuiConfig({
    tools: Tools({ toolkit: openuiIntegration.toolkit }),
  });

  return (
    <AuiProvider extends={aui} config={config}>
      <OpenUIInstructions />
      {children}
    </AuiProvider>
  );
}

export function AgentApp({ runtime }) {
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <OpenUIConfig>
        <YourAssistantUI />
      </OpenUIConfig>
    </AssistantRuntimeProvider>
  );
}
```

The package also exports runtime-agnostic factories and optional Vercel AI SDK continuation helpers. See the complete [`@openuidev/assistant-ui` API reference](/docs/api-reference/assistant-ui) for the supported exports and exact toolkit setup.

## Generation path

Configure the model client used by the assistant-ui runtime with the Gateway API key and compatible base URL. OpenUI instructions teach the model to produce the tool payload; the Gateway validates the OpenUI Lang stream; the assistant-ui renderer displays it inside the conversation.
