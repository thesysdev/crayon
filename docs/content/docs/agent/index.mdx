OpenUI does not require a particular agent framework or chat UI. The renderer consumes streamed OpenUI Lang, so the conversation layer can come from an existing library, an OpenUI SDK, or your own application.

Every integration follows the same workflow:

<Mermaid
  chart={`
flowchart LR
    U["Chat UI or agent SDK"] --> A["Application backend"]
    A --> G["OpenUI Gateway"]
    G --> M["Model"]
    M --> G
    G -->|"corrected OpenUI Lang"| A
    A --> R["OpenUI renderer"]
    R --> U
`}
/>

The Gateway is the default generation path throughout these guides. It keeps model access consistent and corrects invalid OpenUI Lang before the response reaches the renderer.
