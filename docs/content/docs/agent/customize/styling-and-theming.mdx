`AgentInterface` uses two complementary styling systems:

- A built-in `ThemeProvider` maps theme values to `--openui-*` custom properties.
- The `@openuidev/react-ui` stylesheet supplies the component rules that consume those properties.

Theme configuration does not replace the component stylesheet. Import one complete stylesheet once in the application's global entry point.

```ts
import "@openuidev/react-ui/styles/index.css";
```

If the application uses Tailwind or other CSS cascade layers, follow the [`@openuidev/react-ui` styling reference](/docs/api-reference/react-ui#styling) to choose the appropriate stylesheet and ordering.

## Customize theme tokens

Pass a `ThemeProps` object to the `theme` prop. Use `createTheme()` so misspelled or unsupported keys are reported during development.

```tsx
import { AgentInterface, createTheme, type ThemeProps } from "@openuidev/react-ui";

const agentTheme: ThemeProps = {
  mode: "light",
  lightTheme: createTheme({
    background: "oklch(0.98 0.01 250)",
    interactiveAccentDefault: "oklch(0.55 0.18 255)",
    radiusM: "10px",
  }),
  darkTheme: createTheme({
    background: "oklch(0.16 0.02 255)",
    interactiveAccentDefault: "oklch(0.72 0.14 255)",
  }),
};

export function App() {
  return <AgentInterface llm={llm} theme={agentTheme} />;
}
```

When the surrounding application already provides a compatible OpenUI `ThemeProvider`, set `disableThemeProvider` on `AgentInterface` to avoid nesting another provider.
