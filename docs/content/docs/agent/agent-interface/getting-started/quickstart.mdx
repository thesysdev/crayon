---

The OpenUI CLI can scaffold a Next.js agent application with Agent Interface, an OpenUI renderer, and a server route for model generation.

## 1. Create the application

Run the interactive command and keep Gateway as the recommended backend choice:

```bash tab="pnpm" tab-group="pkg"
pnpx @openuidev/cli@latest create
```

```bash tab="bun" tab-group="pkg"
bunx @openuidev/cli@latest create
```

```bash tab="yarn" tab-group="pkg"
yarn dlx @openuidev/cli@latest create
```

```bash tab="npm" tab-group="pkg"
npx @openuidev/cli@latest create
```

## 2. Configure the Gateway key

Create a key in the [Thesys Console](https://console.thesys.dev/keys) and add it to the generated environment file:

```bash
THESYS_API_KEY=sk-th-your-key-here
```

The key stays in the generated server route. Browser code calls your application, never the Gateway directly with this server credential.

## 3. Run

```bash tab="pnpm" tab-group="pkg"
pnpm dev
```

```bash tab="npm" tab-group="pkg"
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and request an interface such as a comparison table or interactive form.
