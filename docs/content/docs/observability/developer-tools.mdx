Start reliability work in development, close to the prompt and component definitions you can change. OpenUI DevTools and the local observability event bus expose the same kinds of runtime signals that become important across production traffic.

## Inspect generated interfaces

OpenUI DevTools can show the response text, parser issues, validation errors, parsed tree, and streaming timeline for a generated interface. Apps using `@openuidev/react-lang` auto-mount the widget in browser development builds.

See [OpenUI Lang Developer Tools](/docs/openui-lang/developer-tools) for installation and the complete debugging workflow.

## Listen to local events

`@openuidev/observability` is a framework-agnostic event bus. It does not send data to a hosted service.

```ts
import { observability } from "@openuidev/observability";

const remove = observability.listen(["warning", "error"], (event) => {
  console.error(event.level, event.detail);
});

// Detach the listener when the integration is removed.
remove();
```

Listen to every level when connecting a custom sink:

```ts
observability.listenAll((event) => {
  reportToYourTelemetryService(event);
});
```

Each event includes a level, timestamp, and typed detail payload with a required `kind`. See [Telemetry](/docs/observability/telemetry) for the event model.

## Move to production

Custom listeners are appropriate when your organization already has a central telemetry pipeline. For OpenUI-specific reliability dashboards, continue with [Production Setup](/docs/observability/production-setup).
