Add `@openuidev/dashboard-kits`: e-commerce, product analytics, and workspace usage dashboard kits — components, data-tool contracts, prompts, and sample data a model composes into dashboards. Built on react-ui's charts (BarChart, HeatmapChart, SegmentedBar), with new kit charts (TrendChart, GoalPace, Tracker, Sparkline, ProfitWaterfall, SegmentFlow, QuadrantChart, SixTwelve, BurnDown) that follow react-ui's chart architecture.
